# LabelFlow 建库执行顺序（唯一真源）
#
# 规则：
#   - 每行一个 SQL 文件名（相对 SQL_DIR，默认 backend/scripts）；# 开头为注释
#   - `@base`  = 基础 DDL（仓库内 docs/03-database.sql；镜像内 /app/docs/03-database.sql）
#   - `@demo <文件名>` = 仅在 --seed-demo 时执行
#   - 顺序不可随意调换，理由见行尾注释
#
# 变更规则：新增迁移脚本必须同时在此登记，否则 db-verify.sh 会报缺表。

wms_p1_inbound.sql                         # WMS 收货/上架
