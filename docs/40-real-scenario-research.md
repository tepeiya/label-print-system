# 40 · 生产企业厂内物流 + UDI 合规：场景对标与差距

> 2026-11-27。定位已确认：**服务医疗器械生产企业（注册人 / 受托生产企业）**，生产执行对接 MES / ERP，
> UDI 数据要报送。本文不再讨论其他业态，只对齐这个定位下的真实标准做法。
> 此前 `docs/24`、`docs/28` 的流程标题沿用了错误的业态表述，已一并修正。

## 1. 这个定位下的角色与系统边界

| 角色 | 在仓库里做什么 | 系统里对应 |
|---|---|---|
| 采购 / 仓库 | 到货接收、IQC 送检、上架、备料、发货 | console + PDA |
| 生产 | 按工单领料、投料、完工报工 | MES / ERP（本系统接收） |
| 质量 QA | 来料检验、过程检验、成品检验、批记录审核、产品放行（电子签） | console（已有） |
| 仓储主管 | 盘点、移库、调整、复核 | console + PDA |
| 注册 / 法规 | UDI 赋码规则、DI 台账、数据库报送 | console + 导出 |

与前端的界面分工：**console 用于管理与审批，PDA 用于现场扫码作业**，两边不重复。

## 2. 与 ERP / MES 的接口契约（必须先定，否则单据全变手工）

建议按"谁主数据、谁下指令、谁回结果"三列定死，任何一项没定就会退化成手打单据。

| 数据/单据 | 主责系统 | 本系统动作 | 时机 |
|---|---|---|---|
| 物料、供应商、客户主数据 | ERP | 只读同步（定时 + 增量） | 每日 |
| 采购订单 PO | ERP | 只读同步 → 收货单必须挂 PO 行 | 下单时 |
| 收货过账结果 | 本系统 | 回写 ERP（入库数量/批次/检验结论） | 过账时 |
| 生产工单 + BOM | ERP/MES | 只读同步（替代现在的手工建单） | 下达时 |
| 领料申请 / 齐套结果 | 本系统 | 回写 MES（可领/缺料清单） | 齐套后 |
| 发料过账结果 | 本系统 | 回写 MES/ERP（实际领用批次与数量） | 过账时 |
| **完工报工（成品数量/批次/工序记录）** | MES | 接收 → 生成**成品入库单** | 完工时 |
| 成品入库 + 放行结果 | 本系统 | 回写 ERP（可销售库存） | 放行后 |
| 销售订单 SO | ERP | 只读同步 → 发货单挂 SO 行 | 下单时 |
| 发货过账 / 签收 | 本系统 | 回写 ERP（发货数量/运单/签收） | 过账/签收时 |
| **UDI（DI 台账、包装层级、unit）** | 本系统 | 按 NMPA 要求报送/导出 | 上市销售前 |

接口形式建议：ERP/MES 侧以 HTTP + JSON 或中间表为主；所有回写带幂等键（单号+行号），
失败可重放。若客户没有 MES，则"完工报工"在 PDA 上做（扫工单 → 报产出数量 → 生成成品入库单），
**但入口与单据必须是同一个**，不能变成两套流程。

## 3. 标准链条（生产企业，七日之内可跑通的最小闭环）

```
PO 同步 ──► 收货单(挂PO) ──► IQC ──► 原料入库(待检区) ──► 上架(合格区)
                                                    │
工单同步 ──► 齐套 ──► 领料出库(发料) ──► 生产/工序 ──► 完工报工
                                                    │
                          FQC ──► 批记录审核 ──► 产品放行(QA 电子签, 密码校验)
                                                    │
                                   成品入库单(成品仓, 批次/效期/数量)
                                                    │
              赋码(unit: DI+PI) ──► 装箱(SSCC) ──► 上市放行 ──► UDI 数据报送
                                                    │
SO 同步 ──► 发货单(挂SO) ──► 拣货 ──► 复核 ──► 出库过账 ──► 运输 ──► 签收
                                                    │
                          客户退货 / 召回 ──► 隔离区 ──► 检验 ──► 处置
```

必须有的辅助作业：**盘点单**（循环盘点 + 差异复盘）、**移库单**（库位间、待检区↔合格区）、
**不合格品隔离区**、**温湿度记录**（试剂/无菌类）、**留样管理**。

法规锚点：
- 《医疗器械生产质量管理规范》第一百零四条：放行须"完成所有规定工艺流程、批生产记录完整、
  质量控制记录完整、异常已处理、**说明书/标签/UDI 赋码符合规定**"，放行后附合格证明；
  第一百零五条：留样与观察记录。
- UDI：上市销售前把**最小销售单元及更高级别包装**的产品标识上传唯一标识数据库；DI 标识
  "注册人+型号规格+包装"，PI 由批号/序列号/生产日期/效期构成；包装层级须成链（unit→箱→托盘 SSCC）。

## 4. 现有实现 vs 标准：差距清单

⛔ = 链条断点（业务跑不通，只能手工补）；⚠ = 真实系统必备但缺失。

| # | 环节 | 现有实现 | 标准要求 | 级别 |
|---|---|---|---|---|
| 1 | 成品入库 | **无单据**，成品库存靠 `/inventory/inbound` 手输 | 完工报工 → FQC → 批记录 → 放行 → 成品入库单 → 上架；待检/合格分区 | ⛔ |
| 2 | 采购订单 | 无 PO，收货单手填 `supplierId`/`sourceNo` | PO 驱动收货，校验品规/数量/超收比例 | ⛔ |
| 3 | 供应商/客户主数据 | 无（发货只能手打客户名） | 主数据 + 资质证照有效期（经营/生产许可） | ⚠ |
| 4 | 销售订单 | 无，发货单手建 | SO 驱动拣货、交期承诺、按单核销 | ⛔ |
| 5 | 库内移库 | `transferStock` 同仓直接抛错 | 移库单（库位间、待检区↔合格区） | ⛔ |
| 6 | 盘点 | 只有调整单 | 盘点单（计划/冻结/差异/复盘），账实定期校准 | ⚠ |
| 7 | 客户退货 | 无单据，只能调整单 | 退货单 → 隔离 → 检验 → 让步接收/报废 | ⛔ |
| 8 | 半成品 / 工序 | 无 WIP；工序仅存在于批记录文本 | 半成品入库/工序转移，或明确"由 MES 承担 + 接口回传" | ⚠ |
| 9 | SN 单件序列号 | 阶段二明确不采集 | 植入类/高值须单件序列号 + 单件追溯 | ⚠ |
| 10 | UDI 赋码 | 有 DI 台账、扫码复核、SSCC 装箱 | 生产时生成 unit（DI+PI）→ 打印 → 装箱层级关联 → 追溯查询 | ⚠ |
| 11 | UDI 数据报送 | 无 | 上市销售前报送最小销售单元及上级包装的 DI 数据；变更维护 | ⛔ |
| 12 | 冷链/存储条件 | 无 | 温湿度记录与超限告警（试剂、无菌类） | ⚠ |
| 13 | 留样 | 无 | 按规程留样 + 观察记录（规范第 105 条） | ⚠ |
| 14 | 不合格品处置 | 有检验/放行，无返工/让步/报废单据 | 不合格品评审 → 处置结论 → 台账 | ⚠ |
| 15 | 发货复核 | 拣货直接过账，无独立复核 | 拣货 + 复核双人（防错发），复核后才可过账 | ⚠ |

## 5. 重建顺序（按依赖，不按界面）

**阶段 0 · 定契约（1 轮）**
与 ERP/MES 定接口（谁主数据、谁下指令、回写字段与幂等键）；定 UDI 报送口径（DI 层级、字段、频率）。
产出：接口文档 + 单据-状态-库存动作三张表。

**阶段 1 · 补三根梁（核心）**
1.1 成品入库：完工报工 → 成品入库单 → 上架，与放行强制串联（未放行不得进合格区、不得发货）
1.2 单据驱动：PO 收货校验、SO 发货核销
1.3 仓内作业：移库单、盘点单、分区（待检/合格/不合格）、发货复核

**阶段 2 · UDI 合规闭环**
赋码 unit → 打印 → 装箱层级（SSCC）→ 报送清单/接口 → 正向反向追溯

**阶段 3 · 界面**
骨架稳定后统一重做 console/PDA，按角色（仓管/质检/生产/发货）分作业面，不按功能堆菜单。

## 6. 仍需你确认的两点

1. 对接的是哪套 ERP / MES（金蝶 / 用友 / SAP / 自研）？—— 决定接口是"标准接口"还是"中间表 + 定制"。
2. UDI 报送首期用**导出文件**（Excel/XML 人工上传）还是**接口直连**？—— 导出可先上线，直连需企业数字证书与备案。
